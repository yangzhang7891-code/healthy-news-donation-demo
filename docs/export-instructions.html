Sådan henter du dine data / How to download your data

Du har ret til en kopi af dine data efter GDPR artikel 15. Du henter dem selv hos platformen — vi ser dem først, når du selv vælger at dele dem.
You have the right to a copy of your data under GDPR Article 15. You request it yourself from the platform — we only see it if you choose to share it.

⚠ Vælg JSON — ikke HTML. Vælger du HTML, kan vi ikke læse filen, og du skal bestille igen.

⚠ Choose JSON — not HTML. If you pick HTML we cannot read the file and you will have to request it again.

1. YouTube — Google Takeout (takeout.google.com)

Dansk

  1. Gå til takeout.google.com og log ind.
  2. Klik Fravælg alle, og sæt så kun flueben ved YouTube og YouTube Music.
  3. Klik Alle YouTube-data medtaget → fravælg alt → vælg kun historik.
  4. Klik Flere formater → sæt Historik til JSON.
  5. Vælg .zip og eksportér én gang. Du får en mail, når filen er klar.

English

  1. Go to takeout.google.com and sign in.
  2. Click Deselect all, then tick only YouTube and YouTube Music.
  3. Click All YouTube data included → deselect all → select only history.
  4. Click Multiple formats → set History to JSON.
  5. Choose .zip and export once. You'll get an email when it's ready.

2. TikTok — i appen / in the app

Dansk

  1. Åbn appen → Profil → menuen ☰ øverst til højre.
  2. Indstillinger og privatliv → Konto → Download dine data.
  3. Under Anmod om data: vælg filformat JSON (ikke TXT).
  4. Vælg alle data, og send anmodningen.
  5. Hent filen under fanen Download data, når den er klar.

English

  1. Open the app → Profile → ☰ menu, top right.
  2. Settings and privacy → Account → Download your data.
  3. Under Request data: choose file format JSON (not TXT).
  4. Select all data, then submit the request.
  5. Collect it from the Download data tab once it's ready.

3. Instagram & Facebook — Accounts Centre / Kontocenter

Dansk

  1. Indstillinger → Kontocenter → Dine oplysninger og tilladelser.
  2. Download dine oplysninger → Anmod om download.
  3. Vælg din konto, og vælg Alle tilgængelige oplysninger.
  4. Sæt format til JSON og datointerval til Al tid.
  5. Send anmodningen, og hent filen, når du får besked.

English

  1. Settings → Accounts Centre → Your information and permissions.
  2. Download your information → Request a download.
  3. Pick your account, then choose All available information.
  4. Set format to JSON and date range to All time.
  5. Submit, then download the file when you're notified.

Bestil i god tid. Det tager typisk fra nogle timer til flere dage, før filen er klar — bestil helst før du kommer forbi standen.

Pak ikke filen ud. Tag .zip-filen med, som den er.

Er din historik sat på pause? Så kan filen være tom. Det er helt i orden — det er også et resultat.

Menuerne ændrer sig af og til. Ser noget anderledes ud, så spørg os ved standen.

Request it early. It usually takes a few hours to several days to arrive — ideally request it before visiting the stand.

Don't unzip it. Bring the .zip file exactly as you downloaded it.

History paused? The file may be empty. That's fine — it's a result too.

These menus change from time to time. If something looks different, just ask us at the stand.
